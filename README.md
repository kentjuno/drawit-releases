# Drawit — Android

App tập vẽ mỗi ngày. Bản web: mở bằng trình duyệt, không cần cài.
A daily drawing-practice app. This repo only hosts the Android APK.

## Tải về / Download

**[⬇ Drawit.apk (bản mới nhất / latest)](https://github.com/kentjuno/drawit-releases/releases/latest/download/Drawit.apk)**

Các bản cũ / older versions: [Releases](https://github.com/kentjuno/drawit-releases/releases)

## Cài đặt (Tiếng Việt)

1. Bấm link ở trên trên điện thoại Android để tải `Drawit.apk`.
2. Mở file vừa tải. Lần đầu Android sẽ hỏi cho phép trình duyệt **cài ứng dụng không rõ nguồn** → bật cho phép rồi quay lại.
3. Bấm **Cài đặt**. Xong là có biểu tượng Drawit trên màn hình chính.
4. Có bản mới: tải lại và cài đè lên, bài vẽ vẫn còn nguyên.

Cần Android 6.0 trở lên.

## Install (English)

1. Open the link above on your Android phone to download `Drawit.apk`.
2. Open the downloaded file. The first time, Android asks to allow your browser to **install unknown apps** → allow it and go back.
3. Tap **Install**. The Drawit icon appears on your home screen.
4. New version: download again and install over the old one — your drawings stay.

Requires Android 6.0 or newer.
